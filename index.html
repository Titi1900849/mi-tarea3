1. Diseño Web Responsivo y Viewport

El diseño web responsivo (RWD) es una filosofía de diseño que propone que el desarrollo y el diseño de un sitio web deben responder al comportamiento del usuario y al entorno (tamaño de pantalla, orientación y plataforma).

El componente crítico para lograrlo en dispositivos móviles es la etiqueta Viewport: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Esto le indica al navegador que ajuste la anchura de la página a la anchura de la pantalla del dispositivo de forma proporcional.

2. Componentes Esenciales de Bootstrap 5

Bootstrap 5 facilita la creación de interfaces modernas gracias a:

  • Containers: Elementos de diseño básicos que contienen, centran y alinean el contenido dentro de un dispositivo.
  • Grid System: Sistema de filas (.row) y columnas basado en Flexbox que divide el ancho de la pantalla en una cuadrícula de 12 unidades.
  • Flexbox Utilities: Clases de utilidad para alinear, centrar y distribuir elementos con flexibilidad.
  • Navbar & Carousel: Componentes interactivos listos para usarse y adaptarse de forma automática en móviles y escritorio.
